Pronto para jogar

O jogo será carregado automaticamente do servidor local. Não é necessário selecionar o disco ou apertar Iniciar no site.

Clique no botão "Ativar som e focar controles" depois de carregar. Teclado: setas para mover; Enter = START; X = botão X do PS1; S = círculo; Z = quadrado; A = triângulo. Controle USB/Bluetooth pela Gamepad API. Se não houver som, clique na tela do jogo para ativar o áudio. Versão experimental: Start, GAME e MODE SELECT funcionando; áudio ainda em otimização, com cortes possíveis. O carregamento pode levar um minuto ou mais, conforme sua conexão e dispositivo.
